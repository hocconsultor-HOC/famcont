# FAMCONT · Contas da Família Martins&Costa

App Android (celular e tablet) para controle das contas da família: pago, em dia, vence logo, atrasado e planejado; semanas dos filhos; contas familiares em parcelas; resumo didático; sincronização entre aparelhos.

**Baixar / atualizar (Android):** https://github.com/hocconsultor-HOC/famcont/releases/download/app-android/FAMCONT.apk

Para atualizar, baixe pelo mesmo link e instale por cima — as contas continuam salvas.
